# Decidr - AI Decision Council

A sophisticated collective intelligence platform that leverages specialized AI archetypes and human intuition to delayer complex decisions.

## Recent Enhancements (v4.5)
- **Background Architect**: Extracts deep situational nuances and frictional realities automatically.
- **Strategic Templates**: Modular starting points with instant-clear tag functionality.
- **Non-Destructive AI Help**: Field-specific intelligence (Questions vs. Real Options) that populates a selection cache instead of modifying your raw input.
- **Integrated Prompt System**: Custom themed modals for a consistent application-wide aesthetic.
- **Resilient Orchestration**: Advanced model fallback for high reliability during peak demand.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
